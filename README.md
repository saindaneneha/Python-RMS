# 🎓 EduInsight – Smart Academic Performance Analyzer

EduInsight is a desktop-based Student Result Management System developed using **Python**, **Tkinter**, and **SQLite3**. It provides an intuitive graphical interface for managing students, courses, examination results, and academic reports while maintaining records securely in a local database.

---

## 📖 Overview

EduInsight simplifies the management of academic records by allowing administrators to manage student information, courses, and examination results from a single application. The project demonstrates GUI development, database management, and CRUD operations using Python.

---

- 🔐 Secure Login System

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/EduInsight.git
```

### 2. Navigate to the Project

```bash
cd EduInsight
```

### 3. Install Required Package

```bash
pip install pillow
```

> SQLite3 is included with Python, so no additional installation is required.

### 4. Run the Application

```bash
python login.py
```
